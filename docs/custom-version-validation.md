## 测试环境修正

已有语言文件加载测试直接比较 JSON 文本，会把 Windows CRLF 与 LF 差异判为内容错误；比较前统一换行即可保持原有内容检查。缩略图日期测试预期为英文，但日期格式原先依赖主机默认区域；测试明确设为 en-US，使断言可复现。两处均修正已有测试，不改变产品行为，也不扩大测试矩阵。

## 本地只读运行检查

Immich ping 接口返回 HTTP 200。发现配对执行器的共享网络连接失效；在确认持久化任务没有运行后，仅重启执行器，连接恢复，配对任务状态接口返回 HTTP 200。该接口保留的一次历史任务状态为 FAILED，进度 412/413；本次未启动或恢复会写入照片堆叠的任务，因此不把接口可用视为该历史任务完成。

浏览器中的目录授权、真实 RAW 同步交互，以及新的真实配对任务未在本次重新执行；上述自动测试、构建和只读运行检查分别提供相应范围的证据。
